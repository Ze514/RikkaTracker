Privacy Policy for RikkaTracker Browser Extension
1. Data Collection
This extension only collects non-sensitive public browsing state data, including active website domain names and browsing duration, solely for the core function of synchronizing web activity time statistics to the ikkaTracker desktop application. We do not collect user personal identity information, passwords, browsing content, sensitive webpage data, or any other private personal information.
2. Data Usage
All collected data is only used locally on the user’s device for time tracking, productivity analysis and timeline visualization. No user data will be uploaded, shared, sold or disclosed to any third parties.
3. Data Storage
All browsing activity data is stored locally on the user’s Windows device only, no cloud server storage is involved. Users can clear all statistical data at any time through the RikkaTracker desktop client.
4. User Rights
Users can disable or uninstall the extension at any time to terminate all data collection behaviors, and completely delete all local statistical data generated by the extension.
5. Policy Updates
We may update this privacy policy as needed. Users will be notified of updates via the official project page.
