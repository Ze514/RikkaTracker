## 一、核心功能需求

### 1.1 应用活动层级模型（树状统计）

每个被监控的应用在任一时刻精确归入以下三种状态之一：

```
应用 (根)
├── [后台应用]
│   条件：有进程运行，但无可视窗口（全部最小化或关闭窗口）
│   说明：不计入前台使用时长，可选记录进程存活总时长
│
└── [前台应用]
    ├── [前台非活动应用]
    │   条件：至少一个窗口可见，且不是当前焦点；或者空闲超时导致降级
    │   说明：计入“前台非活动时长”
    │
    └── [前台活动应用]
        条件：焦点窗口所在应用，且键盘/鼠标有有效交互（未超空闲阈值）
        说明：计入“活跃使用时长”，是用户正在操作的应用
```

#### 状态转换关键事件
- **焦点获取**：目标应用由“前台非活动”或“后台”转换为“前台活动”（前提：窗口可见）。
- **焦点丢失**：当前“前台活动”应用降低为“前台非活动”（若其窗口仍可见）或“后台”（若窗口最小化）。
- **空闲检测**：焦点应用在设定的时长（如可配置的 N 分钟）内无输入，则降级为“前台非活动”；恢复交互时重新激活。
- **窗口显示/隐藏**：最小化或恢复窗口触发前台/后台迁移。
- **进程退出**：完全退出监控。

### 1.2 黑白名单与精细策略

- **全局模式**：
  - 白名单模式：仅统计名单内的应用。
  - 黑名单模式：统计除黑名单外的所有应用。
- **精细策略模式**：可针对单个应用覆盖以下行为：
  - 是否**忽略统计**（彻底不记录）。
  - 是否**启用空闲检测**：关闭则只要该应用处于前台焦点即始终视为“活动”（用于视频播放器、游戏、演示等）。
  - 是否将**后台进程时间**计入特殊统计（如音乐后台播放时长）。
- **媒体/特殊应用预设库**：系统内置一份常见“免空闲检测”应用列表（如 `vlc.exe`, `wmplayer.exe`, `spotify.exe` 等），用户可增删。
- **默认规则**：未命中任何规则的，遵循全局默认行为（全局启用空闲检测、不清空、不忽略）。

### 1.3 空闲静置时长配置

- 全局空闲超时可调（例如 1~30 分钟）。
- 可选行为：空闲后是否将空闲时间段从活跃时长中扣除，或标记为空闲块。
- 可保存多组配置方案（如“标准模式”、“专注模式”等）。

### 1.4 类甘特图时间线（核心可视化）

以甘特图风格直观展示一日（或选定时段）内各应用的活动片段分布。

- **横轴**：可滚动的线性时间轴，精确到分钟。
- **纵轴**：应用名称（可按使用总时长排序或手动排序）。
- **线段表示**：每个连续的活动区间用一条横向线段表示。
  - 目前至少区分**前台活动**（例如深色实线）与**前台非活动**（例如浅色虚线）两种样式，用户可一键切换显示/隐藏其中某一类。
  - **后台运行**区间可选择以更淡的线条显示（可选开关，默认关闭）。
- **交互**：
  - 鼠标悬停显示精确起止时间、持续时长及状态。
  - 点击线段可跳转到该应用该时段的详情页。
  - 支持缩放时间粒度（小时/分钟级）和拖动时间轴。
- **多维度过滤器**：可结合黑白名单、分组标签快速筛选甘特图中的显示内容。

此图表与树状统计模型直接对应，使用户能一眼看清“什么应用在何时、以何种状态被使用”，是数据分析的核心界面。

## 二、扩展功能需求

### 2.1 网站浏览时长树状统计

将网站监控实现与应用监控对等的树状模型：

```
浏览器
├── [非焦点标签页/非活动浏览器窗口] → 计入“前台非活动”或忽略
└── [焦点标签页] → 计入“前台活动”
    └── 精确到域名/具体URL，可聚合到用户自定义的“服务组”（如“Google 服务”）
```

通过浏览器扩展或本地历史数据库分析获取当前焦点标签及活跃状态。

### 2.2 多维度统计报表

- **时间聚合**：今日、昨日、本周、本月、自定义区间。
- **排行榜**：使用时长Top 应用/网站。
- **时段分布热力图**：按24小时×星期几展示活动密度。
- **趋势图**：单个应用/网站在多日内的使用时长变化曲线。

### 2.3 项目/任务维度追踪（进阶）

- 用户可将多个应用/网站归入一个自定义“项目”或“任务”。
- 自动汇总该项目的总投入时长，便于时间记账或绩效评估。

### 2.4 数据隐私与安全

- 所有数据仅保存于加密的本地 SQLite 数据库，无任何云上传。
- **隐私窗口忽略**：当活动窗口标题匹配用户定义的敏感关键词时，暂停记录。
- **数据脱敏导出**：导出报表时可隐藏详细域名或应用名。
- **历史清除**：支持按时间段、按应用维度删除记录，或一键清空。

### 2.5 系统整合与易用性

- **系统托盘与后台运行**：关闭窗口时最小化到托盘，持续监控。
- **开机自启**：可选静默启动。
- **数据导出**：CSV / Excel / PDF。
- **备份与恢复**：手动或自动定时备份数据库到指定位置。

### 2.6 可扩展与二次开发接口

- **本地 Webhook / API**：实时推送当前活动数据到本地服务（如 Obsidian、Notion 时间跟踪插件）。
- **脚本扩展**：允许高级用户用 Lua 或 PowerShell 编写自定义分类规则或事件响应。
